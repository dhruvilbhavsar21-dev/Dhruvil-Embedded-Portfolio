01. Smart Feedback Collection System

ESP32-S3 | LVGL | 7" TFT Touch | HTTP/MQTT APIs | LittleFS

A Wi-Fi enabled interactive feedback kiosk designed to replace paper forms with an automated digital solution. The system features an intuitive LVGL-based UI with dynamic emoji routing. Engineered with robust offline-to-online data synchronization via MQTT/HTTP POST, guaranteeing zero data loss using internal LittleFS logging during network outages.

02. Self-Service Ticketing Kiosk

ESP32-S3 | BHIM UPI APIs | UART Thermal Printer | C++

A low-cost, self-service ticketing kiosk designed for tourist attractions. The system autonomously calculates totals via an LVGL touch interface, generates dynamic BHIM UPI QR codes using matrix arrays, polls cloud payment gateways for secure transaction verification, and utilizes raw ESC/POS UART formatting to instantly issue thermal receipts.

Modular C++ firmware structured for asynchronous execution of UI, networking, and printing.
